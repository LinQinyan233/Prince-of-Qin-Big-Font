# 秦殇大字体替换 Mod

本 Mod 用于替换《秦殇》原版游戏中过小的字体，提升游戏内文字的可读性。字体替换后，文字更清晰易辨，减少长时间游戏带来的视觉疲劳。

## 字体对比

本仓库包含三个字体文件，供对比与使用：

| 文件 | 说明 |
| --- | --- |
| `原版字体` | 《秦殇》原版小字体，字号偏小，阅读较为吃力 |
| `前传字体` | 《秦殇前传》所用字体，相比原版有所改善 |
| `本mod字体` | 本 Mod 采用的字体，**可读性更强** |

## 安装方法

1. 从本页面顶部仓库中下载 `大字体mod.fnt`（或其他所需字体文件）。
2. 备份游戏目录 `font` 文件夹下的 `16Point.fnt` 文件。
3. 将 `大字体mod.fnt` **重命名**为 `16Point.fnt`。
4. 用重命名后的文件替换游戏目录中的 `16Point.fnt`。
5. 运行游戏即可。

> 提示：重命名是为了让游戏按原有文件名加载字体，替换前请务必完成备份。

## ⚠️ 已知问题

**大字体 Mod 在部分小尺寸文本框中会显示不全。**

由于本 Mod 的字形相比原版更大，在游戏内一些**预留空间较小的文本框 / 按钮 / 列表**中，会出现文字被裁切、显示不完整的情况。

这是字体尺寸与固定 UI 框不匹配导致的，属于**已知局限**，并非安装错误。
